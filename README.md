## ¿Qué hace el proyecto? (Propósito y Funcionalidades)
Explicación detallada de las características principales de tu sistema:
* **Módulo de Usuarios**: Login, registro y control de roles.
* **Dashboard General**: Métricas y reportes en tiempo real.
* **Gestión de Datos**: Registro, edición y eliminación de registros (CRUD).

---

## Arquitectura y Stack Tecnológico
Estructura y herramientas utilizadas para construir la aplicación:
* **Frontend**: HTML5, CSS3, JavaScript (ES6+).
* **Backend**: PHP 8.2 (Arquitectura MVC).
* **Base de Datos**: MySQL / MariaDB.
* **Servidor**: Apache / Nginx.

---

## Requisitos Previos
Programas y herramientas obligatorias que se deben tener instaladas antes de ejecutar el proyecto:
* **PHP** >= 8.2
* **MySQL Server** >= 8.0
* **XAMPP / Laragon** (o cualquier servidor local).

---

## Pasos para Instalarlo y Ejecutarlo

1. **Clonar el repositorio**:
    `git clone https://github.com/Obregon-Nilton/prueva-inicio.git`

2. **Acceder a la carpeta del proyecto**:
    `cd prueva-inicio`

3. **Configurar la Base de Datos**:
    * Importar el archivo `database.sql` en tu gestor de MySQL (phpMyAdmin, DBeaver, etc.).
    * Configurar las credenciales en tu archivo de conexión.

4. **Ejecutar el proyecto**:
    * Abrir el servidor local y acceder a `http://localhost/prueva-inicio`.
